# Security policy

This repository is an **academic security-research artifact**. The models, harnesses, and SoC composition under study are not production security products and are not certified.

Issues in this research artifact should be reported through GitHub Issues unless they concern a potentially undisclosed vulnerability in a third-party product.

Do not treat RST-A fail-open early access as a vendor vulnerability disclosure. In this work it is classified `RESET_ASSUMPTION_DEPENDENCY`.

A stale-route finding against a specifically evaluated third-party IOPMP integration, if discussed, is an `RTL_IMPLEMENTATION_DEFECT` of that integration, not an architectural IOPMP vulnerability claim.
